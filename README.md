# Instituto Esperança

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas, com o objetivo de criar um site institucional para uma ONG fictícia chamada Instituto Esperança.

O projeto apresenta informações sobre a instituição, seus projetos sociais e um formulário para cadastro de pessoas interessadas em participar das ações.

## Objetivo

Desenvolver uma interface web responsiva, acessível e organizada, aplicando conceitos de HTML semântico, CSS, JavaScript e Design System.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Responsividade
- LocalStorage
- Git e GitHub

## Funcionalidades

- Página inicial institucional;
- Página de projetos sociais;
- Formulário de cadastro;
- Validação dos campos do formulário;
- Mensagens de feedback;
- Menu responsivo para dispositivos móveis;
- Modo claro e modo escuro;
- Persistência do tema utilizando LocalStorage;
- Exibição dinâmica dos projetos;
- Armazenamento dos cadastros no LocalStorage;
- Recursos de acessibilidade, como `aria-label`, `aria-expanded` e `:focus-visible`.
